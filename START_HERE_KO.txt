OTHER TAB. — GitHub Pages + Umami + Spotify

[1] 배포
- 이 폴더에서 index.html과 assets 폴더를 GitHub 저장소의 최상위에 업로드하세요.
- GitHub 저장소 Settings > Pages > Deploy from a branch > main / (root) 설정.
- 개인 GitHub Pages 예시: https://아이디.github.io/other-tab/

[2] 방문 통계 연결 (필수 사용자 설정)
- https://cloud.umami.is/ 에서 Website 추가.
- 등록한 웹사이트의 Website ID를 복사.
- index.html 파일에서 PASTE_YOUR_UMAMI_WEBSITE_ID 문자열을 찾아 실제 ID로 교체하고 커밋.
- 이 작업 전에는 통계가 작동하지 않습니다. 아이디는 공개 키 성격이고 패스워드/API 비밀 키는 넣으면 안 됩니다.
- 기본: 익명 조회 수/국가·기기·브라우저·유입 경로(표시 가능한 범위)
- 클릭 이벤트: explore_click, nav_collection, nav_about, nav_infj, nav_facts, nav_currently,
  nav_music, tmi_open, back_to_top, music_player_open, spotify_open
- 이벤트/세션 통계는 개인 신원 또는 Discord 계정 식별에 사용할 수 없습니다.

[3] 음악
- Eurythmics — Sweet Dreams (Are Made of This)
- Spotify 공식 임베드. 방문자가 LISTEN HERE를 클릭하면 플레이어가 로딩됩니다.
- 오디오를 무단 업로드하거나 MP3 파일로 재배포하지 않습니다.
- 일부 브라우저/Spotify 계정·지역에 따라 재생 길이/사용 가능 여부가 다릅니다.
- 재생 자체가 아니라 '플레이어 열기'와 'Spotify 열기' 클릭 이벤트만 기록합니다.

[4] 기존 스타일
- 유리 보틀, 흩날리는 꽃잎, INFJ 글라스 오브제, 밝은 크림/핑크 톤 유지.
- 빌드 도구나 Google Apps Script는 필요하지 않습니다.
