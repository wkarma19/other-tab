OTHER TAB. — AI image-based interactive personal website

구성:
- index.html: 반응형 단일 페이지. CSS/JS 내장.
- assets/*.webp: AI로 생성한 개별 투명 오브젝트 이미지.
- desktop-preview.png / mobile-preview.png: 첫 화면 미리보기.

실행:
1. ZIP 압축 해제
2. index.html 더블클릭 (Chrome, Edge, Safari 등)
3. 사이트 공개: index.html과 assets 폴더를 함께 정적 웹호스팅에 업로드

기능:
- 히어로: 메인 보틀과 장식 오브젝트에 상이한 부유 애니메이션
- 데스크톱: 마우스 반응 및 유리병 드래그 시 제한적 기울기
- 취향 이미지: 호버 움직임
- Random facts: 카드 클릭으로 답변 펼치기
- 스크롤 등장 모션, 메뉴, 모바일 대응, 모션 감소 환경 설정 지원

중요:
- 실제 실시간 3D 메시가 아니라 AI로 만든 투명 이미지에 2.5D 효과를 적용함.
- 최초의 레퍼런스 이미지/브랜드 그래픽을 복제하지 않고 별도 이미지로 재구성.
- 문구는 이전 대화에서 나온 소재를 바탕으로 구성한 초안. 공개 전 직접 확인 및 수정 권장.
- 방문자 식별·추적 코드는 포함하지 않음. 일반 방문 통계는 배포 후 별도로 연동 가능.
